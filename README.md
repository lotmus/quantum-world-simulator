# Quantum World Simulator

Interactive physics demonstrations companion to **The Quantum World** by Lothar J. Musiol — the non-fiction companion to the *Lolly Wren's Curious Science Adventures* series.

## Demos

- [Two Slits](https://lotmus.github.io/quantum-world-simulator/index.html) — superposition and interference
- [Bloch Sphere](https://lotmus.github.io/quantum-world-simulator/blochsphere.html) — superposition, visualized
- [Feynman's Glass Trick](https://lotmus.github.io/quantum-world-simulator/glasstrick.html) — sum-over-paths, QED-style
- [Schrödinger's Cat](https://lotmus.github.io/quantum-world-simulator/cat.html) — the thought experiment
- [Quantum Zeno Effect](https://lotmus.github.io/quantum-world-simulator/zeno.html) — measurement freezing a system
- [Quantum Tunneling](https://lotmus.github.io/quantum-world-simulator/tunneling.html) — real closed-form transmission probability
- [BB84](https://lotmus.github.io/quantum-world-simulator/bb84.html) — entanglement and quantum key distribution
- [Bell's Theorem / CHSH](https://lotmus.github.io/quantum-world-simulator/bellchsh.html) — beating the classical limit
- [Quark Confinement](https://lotmus.github.io/quantum-world-simulator/confinement.html) — why quarks never travel alone

All demos run entirely client-side. Nothing is collected or stored.
